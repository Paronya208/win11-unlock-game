# Win11 解密游戏

一款在浏览器里直接运行的短篇网页解谜游戏。

你打开电脑，看到的是一台被人动过手脚的 Windows 11 锁屏界面。
你没有密码。你只知道这台电脑的主人，有一个妹妹。

从锁屏开始，线索散落在回收站、磁盘里的加密文件、聊天记录、
学校官网的成绩表与站内搜索，以及一份旧档案里。

## 在线游玩

**https://Paronya208.github.io/win11-unlock-game/**

（GitHub Pages 托管，打开即玩，无需下载）

## 玩法说明

- **锁屏**：不知道密码，就找找别的方式。
- **桌面**：我的电脑 / 回收站 / 威信 / 搜索 都可以点，也可以右键。
- **回收站**：被删掉的文件可以还原，还原后会出现在桌面上。
- **我的电脑**：D 盘里有加密文件，需要密码。
- **威信**：聊天记录里有信息，也可能有不该看的东西。
- **搜索 / 学校官网**：官网可以登录，站内搜索能搜到人和事。

## 技术说明

- 单个 HTML 文件，约 450 KB，**壁纸以 base64 内嵌**，无外部资源、无网络请求。
- 纯原生 HTML / CSS / JavaScript，无框架、无构建步骤。
- 建议在桌面浏览器或移动端浏览器全屏体验（按 F11 效果更好）。
